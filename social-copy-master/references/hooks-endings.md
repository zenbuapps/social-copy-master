# 鉤子 / 中段 / 結尾 零件庫

用途：① 配貼文時拉開「開頭/結尾」的差異（不重複節奏）；② 使用者要「局部抽換」時，從這挑**不同類型**的零件換——換風味、不只換字。
鐵律：**一批之間，同型鉤子最多 2 篇、同型結尾最多 2 篇**；再多就換型。

---

## 🪝 開頭鉤子（第一行定生死，別每篇同型）

| 類型 | 怎麼開 | 範例 |
|---|---|---|
| 場景/懸念 | 丟進一個具體當下，留個缺口 | 「昨天去公司拿離職申請書的路上…」 |
| 別人嘴裡那句話 | 先講大家都信的那句，再打它（反共識的開法） | 「大家都說 AI 會取代網頁設計師。」 |
| 直接自白/告解 | 一句真情緒開場（脆弱型最有力） | 「老實說，這幾天我有點怕。」 |
| 直球提問 | 問一個讀者心裡有的問題 | 「認真想問，東西做好了卻不敢拿出去，只有我嗎？」 |
| 自問自答 | 有人問我…／常有人說…，其實… | 「有人問我，自己一個人做系統不累嗎？」 |
| 數字/反差結果 | 一個數字 + 一個反直覺 | 「做到 90% 那天，我反而睡不著。」 |
| 引用/觸發 | 從你讀到/聽到的一句切入（拆書型） | 「昨天買了一本書，看到一句話愣住。」 |
| 對話式開場 | 直接引用一句質疑/對話當第一行 | 「『這個你自己一個人做得起來嗎？』」 |
| 時間錨點 | 用時間製造臨場感 | 「三年前的今天，我還在幫別人架網站。」 |
| 身分召喚 | 點名某個身分的內心戲 | 「做了十幾年網站的人，最近常被問同一句話。」 |
| 利益前置 | 把好處放最前（乾貨/教學型強） | 「接案報價要避開的 3 個雷，學起來少做白工。」 |
| be like 框架 | 【身份】的一天 be like／內心小劇場 | 「獨立開發者上線前一週 be like：」 |
| 一句斷言（慎用） | 直接抛信念（限短金句/宣言，別每篇都這樣） | 「保證不是越寬越好，是越設計過越好。」 |

## 🧱 中段抽換手法（不換鉤子結尾，只動主體）
- **換例子/案例**：同一觀點，換一個情境或對象重講。
- **換對比組**：換另一組反差（「WordPress vs 現成工具」→「自己做 vs 找外包」）。
- **增/減列點**：5 點精簡成 3 點，或補一個「反直覺點」。
- **換順序**：把最有共鳴的一點移到最前面。
- **換 murmur（調人味濃度）**：保留乾貨，換掉每點後面的個人吐槽/感受。
- **換數據/細節**：把空泛敘述換成具體數字、人名、畫面感細節。
- **擬人化/比喻**：把抽象概念比喻成具體的東西（「冥想就是心智的間歇性斷食」），瞬間有畫面。

## 🔗 結尾（決定一篇的餘味；別每篇同型）

**A 組 · 沉澱品牌向**（個人品牌、記錄、想留餘味時用）
| 類型 | 怎麼收 | 範例 |
|---|---|---|
| 普世金句 | 拉高一層、可被引用 | 「你以為的大方，其實只是還沒想清楚。」 |
| 反問 | 留一個讓人想 5 分鐘的問題 | 「你賣的，到底是做出網站，還是幫客戶把生意搬上網？」 |
| 留白 | 不講完、戛然而止 | 「招牌換成自己名字的那一刻……懂的人會懂。」 |
| 不撤回 | 把脆弱/大膽的話再說一次，不軟化 | 「我就是有點怕。但我還是要做。」 |
| 回扣開頭 | 收回到開頭那個畫面 | （開頭盯著數字 →）「那個數字，我現在還記得。」 |
| 共勉 | 跟讀者站一起 | 「正在走這條路的人，我們一起。」 |

**B 組 · 衝互動向**（想要留言/收藏/擴散時用；偏 Threads/成長。別變成洗留言）
| 類型 | 怎麼收 | 適合 |
|---|---|---|
| 開放提問 | 「你呢？大家覺得呢？」沒有絕對對錯、人人想插嘴 | 通用 |
| 填空互動 | 「我心目中的好工具＝＿＿＿」（留空格） | 衝留言最強 |
| 共鳴徵集 | 「有人也這樣嗎…？」「誰也有血淚史？」 | 通用 |
| 收藏 CTA | 「準備要 X 的人，先收藏起來」 | 乾貨/教學 |
| 一桿進洞導購 | 內文不放連結，提示「連結放第一則置頂留言」 | 要成交時 |

> 怎麼選：**想沉澱品牌/記錄 → A 組**；**想衝曝光/互動 → B 組**。一批裡別全用同一組、更別每篇都「開放提問」。

---

## 操作提醒（局部抽換時）
- 一次只換使用者指定的那一塊，其餘**逐字不動**。
- 每次給 2–3 個**不同類型**的選項（標 A／B／C），不要給三個換湯不換藥的。
- 挑定後把整篇重組貼出，再附上抽換選單，直到他說「就這篇」。
